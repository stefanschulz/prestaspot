# PrestaSpot

Lightweight PrestaShop integration for WordPress: a plugin that displays content from a connected PrestaShop store — starting with products — as cards (image, name, description, link to the shop), via a Gutenberg block or a shortcode.

## Getting Started

For installation and usage (shortcode, block, settings), see the plugin's own guide: [`prestaspot/README.md`](prestaspot/README.md).
