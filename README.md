# PrestaSpot

Lightweight PrestaShop integration for WordPress: a plugin that displays content from a connected PrestaShop store — starting with products — as cards (image, name, description, link to the shop), via a Gutenberg block or a shortcode.

## Getting Started

For installation and usage (shortcode, block, settings), see the plugin's own guide: [`prestaspot/README.md`](prestaspot/README.md).

## Documentation

* Admin notices are displayed in the WordPress dashboard when the PrestaShop Webservice API encounters errors (e.g., invalid URL, wrong API key, network problems).

Developer-facing documentation — architecture, coding conventions, local Docker test environment, changelog — lives in [`.doc/`](.doc/README.md). Start there if you're contributing code (human or LLM).
